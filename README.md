# cmsc315_unit3_discussion
Unit 3 Discussion
While completing this assignment, I learned how Python lists perform insertion, deletion, and search operations. I gained a better understanding of how inserting or removing elements causes other elements in the list to shift positions. I also learned how a linear search works by checking elements one at a time until a matching value is found or the end of the list is reached.

One challenge I encountered was keeping track of index positions after making changes to the list. When items were inserted or deleted, the positions of other elements changed, which affected later operations. I overcame this challenge by printing the list after each operation and verifying that the results matched my expectations.

List operations can have a significant impact on performance in real-world applications. For example, inserting or deleting data near the beginning of a large list requires many elements to shift, which can reduce efficiency. In contrast, adding an item to the end of a list is generally faster. Applications such as music playlists, contact lists, shopping carts, and social media feeds rely heavily on list operations, making it important to understand how these operations affect overall performance and user experience.
